# Prompt Pin

把常用提示词和随手资料放进 macOS 菜单栏，用快捷键搜索，回车即可复制。

Prompt Pin 是一个原生 SwiftUI + AppKit 小工具，支持按项目整理提示词，以及保存账号、密钥和备忘录。无需注册应用账户，不发起网络请求，不采集使用数据，也没有第三方包依赖。

> **数据安全：当前使用本地明文 JSON 存储，尚未实现应用级加密、主密码或 Touch ID 解锁。界面打码不等于文件加密；导出的备份也包含完整明文内容。请根据这一限制决定是否存放敏感凭据。**

## 功能

- **提示词收藏**：按项目分类、搜索、置顶、编辑和复制完整原文。
- **全局快速搜索**：跨提示词、账号、密钥和备忘录查询，支持方向键选择和回车复制。
- **账号与密钥记录**：支持账号密码、AK/SK、API Key、Token、SSH 私钥、证书及连接字符串；仅保存文本，不连接服务或解析私钥。
- **独立备忘录**：支持多行文字、新建、编辑、搜索和复制。
- **本地保存与备份**：原子写入、上一版自动备份，以及按记录 ID 合并导入。
- **菜单栏常驻**：不占用 Dock，可选登录时自动启动。

## 构建与安装

要求 **macOS 13 或更新版本**，以及 **Swift 6 工具链**（Xcode 或 Command Line Tools）。构建产物适用于当前 Mac 架构。目前仓库未提供预编译 Release，请从源码构建。

```bash
git clone https://github.com/99mrliu/prompt-pin.git
cd prompt-pin
./scripts/build-app.sh
open "dist/Prompt Pin.app"
```

构建成功后，将 `dist/Prompt Pin.app` 复制到 `~/Applications` 或 `/Applications`，再从应用目录或启动台打开。建议安装到固定位置后再开启登录时自动启动；系统可能要求在登录项设置中允许运行。

**更新时，先从菜单栏左下角的设置菜单退出已运行版本，再替换应用。** 应用会阻止同时运行两个实例；旧版仍在运行时，新版会退出。替换应用包不会删除独立保存的资料。

构建脚本仅进行本机 ad-hoc 签名，未使用 Developer ID 签名和 Apple 公证。跨机器正式分发仍需补全相应签名与公证流程。

## 使用

启动后，点击屏幕顶部的图钉图标打开主窗口。首次启动会提供三个可编辑的示例提示词。

### 快速搜索与复制

按 **Option + Command + P（⌥⌘P）** 或 **Control + Command + P（⌃⌘P）**，在任意应用中唤起搜索面板。

1. 输入关键词；不输入时，显示最近编辑的记录。
2. 用 ↑ / ↓ 选择结果，也可以直接点击结果。
3. 按回车复制内容，面板会短暂显示复制确认后关闭。
4. 按 Esc 或点击窗口外部关闭面板。

| 记录类型 | 回车复制的内容 |
| --- | --- |
| 提示词 | 完整正文 |
| 账号 | 密码 |
| AK / SK | SK |
| 其他密钥 | 保存的密钥文本 |
| 备忘录 | 正文 |

如果外接键盘把 Control 映射成了 Command，请使用 **⌥⌘P**，避免实际只发送 ⌘P。也可以在主窗口左下角的设置菜单中点击“快速搜索”。如果快捷键仍未触发，请检查其他应用的快捷键占用情况。

### 日常整理

- 选择项目后新建提示词，或在“全部提示词”“常用置顶”中浏览；点击正文可编辑，卡片菜单提供复制一份、编辑和删除。
- 使用“随身资料”切换账号、密钥和备忘录。账号关系、用途和资源等字段可选，不必为了保存一条资料填写全部字段。
- 密码及密钥默认打码，支持临时查看和逐字段复制。
- 设置菜单提供导入、导出、打开数据文件夹、登录时自动启动和退出。

除全局快速搜索外，下列快捷键仅在应用窗口获得焦点时生效：

| 快捷键 | 操作 |
| --- | --- |
| ⌘N | 新建提示词 |
| ⌘S | 在提示词编辑器中保存 |
| ⌘F | 搜索当前分类 |

## 数据与安全

资料默认保存在应用包之外：

```text
~/Library/Application Support/PromptPin/library.json
~/Library/Application Support/PromptPin/library.backup.json
```

- 保存成功后才更新界面；写入失败会保留编辑内容并显示错误。重新构建、更新应用或重启不会清除这些文件。
- 数据目录创建权限为 `700`，资料文件写入权限为 `600`；这不构成应用级加密，也不能阻止拥有相同用户权限的进程读取文件。
- 复制使用系统剪贴板，目前没有定时清空功能。处理凭据时请留意剪贴板管理器及其他应用。
- 导出的 JSON 包含完整资料，应作为敏感文件保管。请勿上传真实资料库、备份、密钥或带有敏感内容的截图到仓库、Issue 或公开聊天。
- 文件损坏或版本不兼容时，应用会停止编辑和写入。自动备份仅保留上一版，不能代替长期备份。
- 当前没有云同步功能。请自行安排备份；FileVault 可以提供磁盘加密保护，但不能替代应用级加密。

导入按 UUID 合并，不覆盖相同 ID 的已有记录。旧版资料兼容、损坏恢复和字段说明见 [数据格式与恢复](docs/data-format.md)。

## 开发与检查

```bash
swift build
swift run PromptPinCoreChecks
```

`PromptPinCoreChecks` 使用合成测试数据，覆盖持久化、备份恢复、旧数据兼容、导入合并及跨类型快速搜索；断言失败会以非零状态退出。它是不依赖 XCTest 的可执行检查程序，也适用于仅安装 Command Line Tools 的环境。

开发或截图时，可通过 `PROMPT_PIN_DATA_DIR` 指定独立目录，避免与日常资料混用：

```bash
PROMPT_PIN_DATA_DIR="$(mktemp -d)" swift run PromptPin
```

运行独立开发实例前，应退出已安装的应用。公开截图只使用示例资料，不展示真实账户或密钥。

如果 Command Line Tools 存在旧版残留，出现 `PackageDescription` 符号错误或重复 `SwiftBridging` 模块，可尝试兼容模式（需要 Python 3）：

```bash
PROMPT_PIN_COMPAT=1 ./scripts/build-app.sh
PROMPT_PIN_COMPAT=1 ./scripts/swift.sh run PromptPinCoreChecks
```

兼容模式只在 `.build/compat` 创建模块副本与文件系统映射，不修改系统工具链，不需要管理员权限；正常工具链无需开启。

```text
Sources/PromptPin/          菜单栏、SwiftUI 界面、快捷键、剪贴板和登录项
Sources/PromptPinCore/      数据模型、搜索、校验、存储与备份恢复
Tests/PromptPinCoreTests/   核心行为检查与合成测试数据
docs/                      数据格式及恢复说明
scripts/                   应用打包、图标生成与可选工具链兼容
```

反馈问题时，请提供 macOS / Swift 版本、复现步骤、预期和实际结果。请使用合成数据复现，不附真实资料导出文件。
